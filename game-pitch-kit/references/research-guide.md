# 調査の型

判定(🟢/🟡/🔴)の根拠を作るための調査手順。判定に使わない情報は集めない。調査は広く浅くではなく、**「このアイデアを止める理由があるか」を探す方向**で行う。止める理由を探して見つからなかった、が🟢の根拠になる。

## 1. 既出チェック

- コンセプトを表す語の組み合わせで検索(日本語と英語の両方。インディー・海外作は英語でしか出ない)
- Steam・ストア・itch.ioでのタグ/ジャンル検索に相当する語も試す
- 見つかった場合: 単なる既出は🔴の理由にならない。見るべきは「先行作とどう差別化するのか、その差別化に価値があるか」。先行作が強力(高評価・大きなプレイヤーベース)で、本作の差別化が言えないなら🔴候補
- 見つからない場合: 「誰もやっていない」は「宝の山」と「誰かが試して失敗した/成立しない理由がある」の両方がありうる。**なぜ空白なのかの仮説**を立てて、失敗作がないかを追加検索する

## 2. 競合と市場のシグナル

- 近いジャンル・近い体験の代表作を3〜5本特定し、実績のシグナルを拾う(レビュー数・評価・同時接続・売上報道・サービス継続年数など、公開情報で見えるもの)
- **同ジャンルの死んだ作品**を最低1本は探し、死因(市場がなかった/運営が続かなかった/競合に負けた/マネタイズ不全)を推定する。成功例だけ集めない
- 市場の大きさを示す数字が報道等で拾えれば添える。拾えなければ「定量シグナルは確認できず」と書く(それらしい数字を作らない)

## 3. 実現の前例

- コアの仕掛け(技術・運用・コンテンツ供給)が成立した前例を探す
- 前例がない場合、それが「技術的に新しいから」なのか「やっても成立しないから」なのかを切り分ける仮説を書く
- 運用型の場合、そのコンセプトでコンテンツを供給し続けた前例があるかも見る(初動は成立しても供給が続かないジャンルがある)

## 4. 明らかな地雷の一次スクリーニング

詳細はgame-legal-reviewの領域。ここでは一目でわかるものだけ:

- 他社IP・実在作品への依存が前提になっていないか
- 換金・賭博・射幸性の構造が核になっていないか
- プラットフォームが明確に禁止しているもの(暗号資産等)が核になっていないか

該当したら、その時点で🔴または🟡(条件=その要素を外せるか)に直結させ、深掘りはlegal-reviewに送る。

## 調査結果の書き方

- 各項目に「調べた方法(検索語の系統)/わかったこと/わからなかったこと」を残す
- わからなかったことを、わかったことのように書かない
- 出典が怪しいもの(まとめサイト・伝聞)だけを根拠に判定しない
