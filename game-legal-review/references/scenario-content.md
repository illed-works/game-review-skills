# シナリオ・表現内容のレビュー

企画書・仕様書ではなく、**シナリオテキストそのもの**(台詞・地の文・演出指示・フレーバーテキスト・アイテム説明文)をレビューする際に使う。名称・商標のチェック手順はtrademark-naming.mdとcultural-expression.mdに委譲し、このファイルは「書かれた内容・描写」のチェックに集中する。

## レビューの入力と下ごしらえ

1. シナリオから以下を機械的に抽出してリスト化する:
   - 固有名詞(人名・地名・組織名・アイテム名・技名) → trademark-naming.md と cultural-expression.md の名称チェックフローへ
   - 実在への言及(実在の人物・企業・商品・事件・宗教・国・民族)
   - 強度の高い描写シーン(暴力・性・死・薬物・ギャンブル・犯罪の各シーン)
2. 対象年齢(狙いたいレーティング)と展開市場を確認する。**狙うレーティングが決まっていないとチェック基準が決められない**ので、未定なら最初に聞く

### 名称チェックの取りこぼし防止(必須)

シナリオレビューを依頼されると描写のチェックに意識が向き、**抽出した固有名詞の商標・多言語チェックが実行されないまま終わる事故が起きる**(実際に起きた失敗)。以下のどちらかを必ず行い、レポート冒頭の「今回のレビュー範囲」に結果を書く:

- **実行する**: タイトル・主要キャラ名など主要な固有名詞について、trademark-naming.md と cultural-expression.md のフローを走らせる
- **実行しないなら明示する**: 「今回は描写のみをレビューし、固有名詞◯◯・△△の商標調査と多言語チェックは未実施。タイトル確定時に別途推奨」と書く

黙って飛ばすのが最悪の結果になる。ユーザーは「シナリオをレビューしてもらった」と認識し、名称リスクも見てもらえたと誤解したまま先に進むため。

## 1. 差別・蔑称(台詞・描写レベル)

- 台詞に蔑称・差別表現が含まれていないか。**悪役の台詞として意図的に使う場合**でも、(a)物語上の必然性があるか、(b)作品がその価値観を肯定していない構造になっているか、(c)レーティング・ストア規約上許容されるか、の3点で評価する。「悪役だからOK」で素通りさせない
- 属性(民族・国籍・障害・性的指向・職業・容姿)とキャラクターの役割の紐付けがステレオタイプ強化になっていないか(例: 特定の訛り・口調と悪役性の紐付け)
- 病気・障害を「呪い」「穢れ」等の物語装置として使う場合の描写の扱い
- 現代の感覚では問題のある歴史的表現を時代物で使う場合、注記や言い換えの選択肢を提示する

## 2. 宗教(描写レベル)

- 実在宗教の神名・預言者・聖典の引用や言及。台詞での冒涜的な使い方(実在の神名を罵倒語・ギャグに使う等)は名称チェックより深刻になりやすい
- 実在の宗教儀式・戒律をゲーム内で戯画化・攻撃対象化していないか
- 架空宗教を作る場合も、実在宗教の固有要素(シンボル・聖句・固有名)をそのまま流用していないか。「架空」と言い張れる距離があるかを見る
- 死生観の描写(輪廻・天国地獄・葬送)が特定宗教の教義を否定・揶揄する形になっていないか

## 3. 国・地域タブー(プロット・描写レベル)

- 実在の戦争・虐殺・災害・テロ事件を想起させるプロット展開(名前を変えていても、構図・日付・地名の組み合わせで特定されるケース)
- 実在国家・政府・王室の否定的描写(市場によっては不敬罪・侮辱罪の対象になる国がある。該当市場に出すなら検索確認)
- 地図・国境・地名・領土の扱い(cultural-expression.mdの国別規制と接続)
- 歴史上の実在人物の登場・改変(英雄の悪役化、女体化等の改変は市場によって炎上リスクの温度差が大きい)

## 4. 年齢レーティング(CERO/IARC/ESRB/PEGI)に効く表現

**前提**: レーティング基準の詳細は非公開部分も多く、ここでの判定は「どの区分を狙うなら、どの描写が争点になるか」の一次スクリーニング。区分の確定は審査機関の判断。基準・運用は変わるため、際どい判定をする際は最新の審査事例を検索確認する。

対象年齢に効く表現カテゴリ(CEROの審査対象表現とおおむね対応):

- **暴力**: 出血の色と量、欠損・切断、死体の描写(残留するか消えるか)、対人暴力か対モンスターか、殺傷の快楽的演出。**「何が起きるか」より「どう見せるか」が区分を分ける**(同じ死亡イベントでも、画面外/暗転なら下の区分、明示的な出血・欠損描写なら上の区分)
- **性的表現**: 露出度、性行為の示唆・描写、性的な文脈のカメラワークや台詞、着替え・入浴シーン
- **言語・思想**: 台詞の卑語・罵倒語の強度、性的なスラング
- **反社会的行為**: 犯罪の肯定的描写・詳細な手口、いじめ、自殺・自傷、虐待、飲酒・喫煙(特に未成年キャラ)、薬物、ギャンブル
- **恐怖**: ホラー演出の強度(ジャンプスケア、精神的圧迫)

チェックの出力: 狙うレーティング区分を仮置きし、「この区分を狙うなら争点になるシーン」を列挙して、(a)描写を調整して区分内に収める案、(b)描写を維持して上の区分を受け入れる案、の両方を提示する。区分が上がることの事業影響(販路・広告制限)はgame-biz-reviewの領域として言及だけする。

- 配信先ごとの窓口の違いに注意: 国内コンシューマはCERO、スマホストアはIARC(質問票ベースの自動判定)、Steamは自主申告+成人向けは別途サーベイ。同じ内容でもプラットフォームごとに判定・要求が異なる

## 5. センシティブ描写(レーティングと別枠で扱うもの)

- **自殺・自傷**: 方法の具体的描写は最も危険度が高い。示唆に留める書き換え、コンテンツ警告表示の追加を提案する。プラットフォームによってはセンシティブコンテンツの事前警告や年齢制限の要求がある
- **精神疾患・依存症**: 病名を悪役性・危険性の説明として使っていないか
- **未成年キャラの扱い**: 性的文脈への接近は距離があっても最重要の赤信号として扱う(ストア規約・各国法の両面で最も厳しい領域)。未成年キャラの飲酒・喫煙・暴力被害の描写強度も区分に直結
- **動物への残虐行為**: 一部市場・プラットフォームで独立した審査項目になっている

## 6. 実在への言及(名称チェックで拾いきれないもの)

- 実在の企業・商品をモデルにした架空企業(名前を変えても、ロゴ・業態・事件史でモデルが特定される描写)は、否定的に描く場合に名誉毀損・信用毀損リスク
- 実在人物をモデルにしたキャラクター(故人含む)。パブリシティ権・名誉感情への配慮。パロディの安全距離は日本法では狭めに見る
- 歌詞・詩・書籍からの引用(1行でも著作権の対象。引用要件を満たすか、権利処理するか、削るか)

## レポートでの書き方

- 指摘は必ず**シーン・行の特定**(章・シーン名・台詞の冒頭数語)とセットにする。「全体的に暴力表現が強い」ではレビューにならない
- 各指摘に書き換え案を付ける。書き換え案は**物語上の機能(そのシーンが何のためにあるか)を維持したまま**描写強度だけを調整する方向を最優先にする。シーンの意図を殺す修正案は最後の手段
- 重大度は「🔴 ストア規約・法・最重要タブーに触れる(市場喪失級)」「🟡 狙うレーティングの争点になる/特定市場で炎上リスク」「🟢 確認したが問題なし」で付け、レーティングの争点は🔴と混ぜない(レーティングは「どの区分で出すか」という事業判断であり、違反ではないため)
- シナリオは分量が多いので、全文レビューの場合は「章ごとの指摘一覧+全体総評」の構成にする
