# 海外の規制チェック(GDPR・ルートボックス・未成年保護)

日本国内法はjp-regulations.md、こちらは海外市場に配信する場合の規制。**Steam配信は実質グローバル露出**なので、「海外展開の予定はない」つもりでもSteamに出すならこのファイルの照合対象になる。規制は国ごとに動きが速い領域なので、該当したら必ず現行状況をweb検索で確認する(特にルートボックス規制は各国で立法・判例が進行中)。

## 1. ルートボックス(有償ガチャ)規制

**トリガー条件**: 「有償で入手するランダム型アイテム提供」が企画にあれば即照合。無償ガチャのみ・確定内容の販売のみなら対象外だが、「有償通貨で回す無償扱いのガチャ」のような設計は有償とみなされる前提で見る。

国・地域別の危険度マップ(状況は必ず検索確認):

- **ベルギー**: 有償ルートボックスを賭博と認定し事実上禁止した代表国。大手が同国でのガチャ提供を停止した実績がある。対応の定番は「ベルギー(および同様の国)を配信地域から除外する」か「同地域向けにガチャを無効化する」
- **オランダ**: 賭博認定を巡って行政と司法の判断が動いた国。最新の判例・行政方針を検索確認
- **中国**: 排出確率の公開義務が法制化されている。中国展開するなら確率表示仕様が必須要件になる(版号制度と合わせてこちらで扱う)
- **英国・EU各国・米国州法**: 自主規制強化〜立法検討が継続的に動いている領域。重点市場に含まれるなら現在の状況を検索
- **オーストラリア**: ルートボックスを含むゲームのレーティング引き上げ(成人推奨区分義務化)の制度変更があった。レーティング戦略(scenario-content.mdの区分検討)と接続する
- **プラットフォーム側の対応**: Apple/Googleの確率表示義務はplatform-terms.mdに記載済み。IARCの質問票にもランダム型課金の申告項目があり、申告内容がレーティング表示に反映される

チェックの出力: 「有償ガチャあり × 配信地域」のマトリクスを作り、地域ごとに「そのまま配信可 / 確率表示等の対応が必要 / 除外またはガチャ無効化を推奨 / 要検索確認」を割り当てる。ガチャが収益の柱の企画では、除外対象市場の売上インパクトをgame-biz-reviewの論点として送る。

## 2. GDPR・海外プライバシー規制

**トリガー条件**: EU圏からアクセス可能なオンライン要素(アカウント、ランキング、アナリティクス、広告SDK)があれば照合。「EUを狙っていない」でも、ブロックしていなければEUユーザーは来る。

- **GDPR(EU/EEA)**: 個人データ処理の同意取得、プライバシーポリシーの明示、データ主体の権利(削除・開示請求)への対応窓口、越境データ移転の整理。ゲームで見落としやすいのは**広告SDK・アナリティクスSDKが自動送信するデータ**(デバイスID、行動ログ)で、自社がデータを「集めているつもりがなくても」SDKが集めていれば処理者責任が生じる。仕様書のSDK一覧を照合対象にする
- **子どもの同意年齢**: GDPRは16歳未満(加盟国により13〜16歳)は保護者同意が必要。低年齢向け企画では設計レベルの論点になる
- **COPPA(米国)**: 13歳未満からのデータ収集に保護者同意が必要。「子ども向けと判断されるか」は自己申告でなく実態(絵柄・内容)で判定される点に注意。子ども向け判定されると行動ターゲティング広告がほぼ使えなくなり、収益モデルに直撃する
- **米国州法(CCPA/CPRA等)・中国PIPL・韓国PIPA**: 重点市場に含まれる場合のみ個別確認。共通する実務は「プライバシーポリシー整備」「オプトアウト手段」「SDKのデータフロー把握」
- **Cookie・トラッキング同意**: ブラウザゲームはePrivacy系のCookie同意バナーが必要になるケースが多い。Web配信企画では確認項目に入れる

チェックの出力: 「収集するデータの一覧(SDK経由含む)× 配信市場」を洗い出し、(a)プライバシーポリシーに書くべきこと、(b)同意UIが必要な箇所、(c)年齢確認の要否、をリスト化する。ポリシー文面の作成自体は弁護士またはひな形サービスの領域として要専門家相談リストへ送る。

## 3. 未成年保護・その他の海外規制

- **中国の未成年ゲーム時間・課金規制**: 未成年のプレイ時間と課金額の制限が制度化されている。中国展開には実名認証システムの組み込みが前提になる(最新の運用は検索確認)
- **韓国**: 確率型アイテムの確率表示義務が法制化された。韓国展開するなら表示仕様が要件になる
- **EUのダークパターン・消費者保護**: 誤認させる課金導線、解約困難なサブスク、「残りわずか」等の偽の希少性表示は、消費者保護規制と各ストアポリシーの両面で問題化が進んでいる領域。課金UIの仕様が書かれた仕様書では照合する
- **ゲーム内通貨の表示規制**: 実通貨との換算を分かりにくくする多段通貨(課金→一次通貨→二次通貨)への規制議論がEUで進行中。多段通貨設計の企画では最新動向を検索

## チェックの型

1. 企画から「収益モデル(ガチャ有無)」「オンライン要素・SDK」「配信市場」「対象年齢」の4点を抜き出す
2. 上記のトリガー条件と突き合わせ、該当ブロックだけ深掘りする(全部を毎回やらない)
3. 国別の規制状況は記憶で断定せず、該当国×論点で検索してから書く
4. 対応コスト(地域除外、確率表示実装、同意UI、実名認証)は事業判断に跳ねるので、金額感が絡むものはgame-biz-reviewの論点として明示的に送る
