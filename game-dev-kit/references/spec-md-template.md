# spec.mdテンプレート

構成(ID制、スコープ外、データ全件確定、数式、フェーズ+受け入れ条件、実装しない判断リスト)は崩さない。`{{ }}` を埋め、章はプロジェクトに応じて増減してよいが、削ってよいのはゲーム内容の章のみ。§1(目的とスコープ外)、フェーズ計画、最終章(実装しない判断)は必須。

書き方の鉄則:
- 全仕様にID(S-1, S-2...)を振る
- 数値・確率・費用・時間は具体値で確定。「適切に」「バランスよく」禁止
- データはユーザーへの質問ではなく、こちらでたたき台の表を作って提示→修正してもらう
- 受け入れ条件は「非エンジニアがブラウザで触って目視確認できる文」で書く
